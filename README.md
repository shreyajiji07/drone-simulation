# Drone Simulation

A 3D drone flight simulator built using Python and the Ursina Engine.

The simulator provides an interactive 3D environment where the player can control a drone, fly around the map, and navigate through a procedurally generated environment.

## Features

- 3D drone flight
- Procedurally generated buildings
- Landing pads
- Keyboard-based flight controls
- Interactive 3D environment
- Windows executable build

## Built With

- Python
- Ursina Engine
- PyInstaller

## Requirements

- Python 3.x
- Ursina
